# Anthrise 首轮分支预览交付

## 本轮范围

本轮按附件“先做一个产品详情页完整样例 + 一个园区局部区域验证”的要求交付。以 ess16 / AE-E-DAWN-16 为主，hybrid6、series_horizon、origAEV2500、jcLight28 共用相同图鉴组件验证；共增强 20 个原有四语言产品页。其余 71 条 SKU 没有删除，继续使用原详情页并可从分类检索访问。本轮不宣称全园区照片级改造完成。

## 可操作审阅

在本任务 **Preview** 内打开 `/home-zh.html`，可使用园区卡片中的“查看产品图鉴”，直接进入 `/products/ess16-zh.html`。图鉴精选栏可以切换另外四款；全球语言选择器的 EN / 中文 / ES / RU 保持同一 SKU。手机分类为抽屉，参数与资料区可滚动。分享状态 `/home-zh.html?campus-time=night` 会使用原按钮与桥接立即显示夜景，不改变官网默认白昼。

图鉴中可切换实际目录图库、放大/缩小、0 或双击复位、专注/退出、Escape、展台深浅背景、分类/全目录搜索、真实同类规格对比以及完整高分辨率图片。360 按钮明确禁用。咨询入口只预填真实型号至原项目询盘表单，不发送邮件；跨语言草稿只使用同一浏览器的 sessionStorage，未接入远程数据库。

园区可切白昼/夜晚、能量显示/隐藏、暂停、区域漫游和原热点。家庭区域新增真实屋瓦、窗框、墙体技术凹槽、安装轨、雨槽落水管、光伏固定件、接触台座与四脚轮。12 个实际局部灯具具有限距离和 decay=2；软件 GPU 只分配最近的 4 个局部物理光源、手机最多 6 个、硬件桌面全部，并在软件 GPU 上直接切换昼夜以避免交叉淡化过多重绘。其他灯具外观与既有几何并未删除。汽车只有三个固定停车位，没有运动更新、路线上车流或碰撞。

## 本轮不做的事

没有迁移到 React 或加入第二版 Three.js，没有重建产品真值数据，没有改官网 CNAME、SEO canonical、hreflang、结构化数据、GitHub Actions 或 main，没有合并或发布。原 Risey、Products 入场状态机、圆盘、拖动、分页与主页控制器文件哈希均与基线完全一致；只在新图鉴页面隔离其浮层，避免遮挡。

## 仍然真实存在的缺口

没有厂家的精确 GLB/CAD 或完整转台。产品图鉴是产品图片检视，不是 360°。园区硬件仍是放大的概念外形：ess16 原示意柜体约 900×440×1650 mm，而当前目录为 480×235×874 mm；hybrid6 原示意约 900×540×1180 mm，目录为 330×228×433 mm。本轮保持原热点与线缆锚点，未冒充按真实尺寸完成校准，也未新增未知背部接口和孔位。需要厂家外形图、端口/安装图、可信材料纹理和统一尺度的建筑/PBR 场景资产后才能继续做到附件的照片级最终标准。

程序化建筑与灯光已经可视检验，但不是实景案例或核准电气方案。16 kWh 与 6 kW 不代表任意设备自动兼容；工商业柜体的纯 DC 电池与外置逆变器 AC 功率保持区分。模型清单的 verifiedViews 只代表本地文件存在及目录关联，不代表厂家验证了角度或几何。
